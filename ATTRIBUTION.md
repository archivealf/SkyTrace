# SkyTrace V3.3.1 data licences and attribution

SkyTrace uses the following data/services in public commercial builds. Provider terms remain controlling and can change independently of SkyTrace.

## Enabled in public commercial builds

- **ADSB.lol** — primary live aircraft positions/telemetry and active-aircraft enrichment. ADSB.lol publishes its API/data under the Open Database License (ODbL) 1.0. SkyTrace identifies ADSB.lol as the live source and retains attribution with distributed builds.
- **Mictronics aircraft database** — registration/type/model/operator reference data refreshed during the build from the tar1090-db CSV mirror. The aircraft database is distributed under the Open Data Commons Attribution License (ODC-By) 1.0. SkyTrace credits Mictronics as the database source.
- **VRS Standing Data via ADSB.lol** — callsign-to-route standing data used for route enrichment. The ADSB.lol standing-data mirror is published under CC0 1.0.
- **MET Norway Locationforecast 2.0** — global general weather. Data from MET Norway is used under CC BY 4.0 / Norwegian Licence for Open Government Data (NLOD) 2.0 as applicable. SkyTrace identifies itself in requests, caches responses and displays the attribution “Data from MET Norway”.
- **NASA GPM IMERG through NASA GIBS** — global satellite precipitation-rate imagery. SkyTrace labels this layer **Precipitation** because it is a satellite precipitation estimate, not a conventional weather-radar composite. Attribution: NASA GPM IMERG / NASA Global Imagery Browse Services (GIBS).
- **OurAirports** — airport, runway, frequency and navaid reference data. OurAirports releases its downloadable data to the Public Domain; credit is appreciated.
- **AviationWeather.gov** — aviation weather products such as METAR, TAF, SIGMET and PIREP/AIREP data.
- **OpenFreeMap** — map styles/tiles. Commercial use is permitted. MapLibre displays the required OpenFreeMap/OpenMapTiles/OpenStreetMap attribution.
- **MapLibre and other bundled open-source libraries** — used under their respective licences.

## Providers intentionally not used by the public commercial runtime

SkyTrace does not ship or call the following hosted integrations in the public commercial build unless suitable commercial permission is obtained in a future release:

- OpenSky Network REST API
- ADSBDB hosted enrichment API
- Open-Meteo free hosted API
- RainViewer public API

The release verifier scans the commercial runtime for these restricted provider hosts so they cannot be silently reintroduced by an old configuration or build step.

Airline liveries in map markers are simplified informational colour treatments generated by SkyTrace, not aircraft photographs.
