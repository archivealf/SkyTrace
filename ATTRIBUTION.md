# SkyTrace V2 attribution

SkyTrace uses or can use:

- OpenSky Network — live aircraft state and trajectory data.
- OurAirports — public-domain airport, runway, frequency and navaid reference data.
- OpenFreeMap — map tiles/styles displayed with MapLibre attribution.
- Open-Meteo — weather data, CC BY 4.0 data attribution required.
- RainViewer — optional weather-radar imagery under RainViewer's public API terms.
- Simple Icons — CC0 icon package. Brand/trademark rights remain with the respective owners.
- SkyLink API — optional aircraft registry/type/photo enrichment subject to the user's SkyLink plan/terms.

Airline liveries in the map markers are simplified informational colour treatments generated by SkyTrace, not aircraft photographs.
