# SkyTrace V3.3.1 data licences and attribution

SkyTrace uses or can use the following data/services. Provider terms remain controlling and can change independently of SkyTrace.

## Enabled in public commercial builds

- ADSB.lol — primary live aircraft positions/telemetry. Public API/data are provided under the Open Database License (ODbL) 1.0. SkyTrace identifies ADSB.lol as the live source and retains this attribution with distributed builds.
- OurAirports — airport, runway, frequency and navaid reference data. OurAirports releases its downloadable data to the Public Domain; credit is appreciated.
- OpenFreeMap — map styles/tiles. Commercial use is permitted. MapLibre displays the required OpenFreeMap/OpenMapTiles/OpenStreetMap attribution.
- AviationWeather.gov — aviation weather products such as METAR, TAF, SIGMET and PIREP/AIREP data.
- MapLibre and other bundled open-source libraries — used under their respective licences.

## Disabled in public commercial builds unless separately licensed

The V3.3.1 public release build disables these hosted integrations even if an older local configuration enabled them:

- OpenSky Network REST API — commercial or operational use requires a written licence from OpenSky Network. Public commercial builds force ADSB.lol as the live provider and disable OpenSky fallback.
- ADSBDB — SkyTrace does not use the hosted aircraft/route enrichment endpoints in public commercial builds while upstream route-data redistribution/publication permissions remain unsuitable or unclear for this release. Written permission can be added later before re-enabling it.
- Open-Meteo free hosted API — the free endpoint is for non-commercial use. Public commercial builds disable general weather from that endpoint. A future release can use Open-Meteo's commercial customer endpoint with an appropriate subscription and attribution.
- RainViewer public API — commercial integration requires separate terms. Public commercial builds disable RainViewer radar imagery until those terms are in place.

Local/development builds may retain these integrations for evaluation or prototyping only where the provider's terms permit that use.

Airline liveries in map markers are simplified informational colour treatments generated by SkyTrace, not aircraft photographs.
